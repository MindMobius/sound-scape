# 声景品牌标记

标记由三枚不对称的圆润膜片围出中央声口。三枚膜片对应环境、事件与媒介三类可编排声音，中央留白表达它们在同一个场景中彼此呼吸，而不是被封闭成一个短循环。

## 文件

- `soundscape-mark-cutout.png`：正式透明位图母版，直接从确认的参考图抠出三枚膜片，不再重绘轮廓。
- `soundscape-mark-ui.png`：从正式母版缩放得到的 96px 界面派生图，用于导航和播放器等小尺寸场景。
- 现存 SVG 仅保留历史实验，不得用于产品界面、品牌校样或平台图标。

## 几何与颜色

- 单色墨色：`#111513`
- 平台纸色：`#F4F1EC`

标记必须保持位图中的朝向、三枚膜片相对关系和中央留白。默认净空由透明母版直接提供。界面以 PNG 透明通道作为遮罩：日间使用深墨色，夜间使用灰白色；不得再用矢量路径近似轮廓。

## 使用边界

- 不旋转、不描边、不增加投影、渐变或玻璃效果。
- 不单独移动、缩放或重新着色其中一枚膜片。
- 不把标记放进圆形、花瓣或播放按钮轮廓中。
- 大尺寸宣传画面可以从透明母版建立裁切，小尺寸和界面标记继续使用同一份 PNG 透明通道。
- 中文字标尚未定稿；在字体与授权明确前，不从生成图片描摹“声景”字形。
