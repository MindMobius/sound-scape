# 声景资源库

本目录采用静态优先策略。产品默认只消费 `catalog.json` 中登记的静态位图；动态视频、运行时厚度图和渲染实验统一放在 `experiments/`，不进入默认资源清单。

## 目录

- `audio/`：跨端声音目录与原始音频母版，逐文件记录来源、哈希和发布资格。
- `brand/`：跨场景复用的品牌母版，按背景、图集和构图组件分类。
- `scenes/`：每个声景一份内容清单；`playable-scenes.v1.json` 只为已经具备真实声音的场景绑定试听素材、调色板与 `SceneRecipe`。
- `platform/`：平台专属的可缩放资产；当前 `web/` 保存 favicon、Maskable 和单色图标母版。
- `ui/`：不能由字体、CSS 或图标库表达的正式界面资源，以及已验收并登记的渲染运行时输入。
- `experiments/`：动态、GPU 和其他尚未进入产品基线的实验资产。
- `catalog.json`：应用可直接读取的静态资产总目录，也是文件、场景归属、尺寸、提示词和哈希的权威索引。
- `derivatives.json`：从已登记母版导出的 Web 传输版本，记录来源、裁切策略、尺寸和哈希；未知的历史编码参数必须明确标记，不能补写猜测值。
- `runtime-pack.v1.json`：Flutter 包内资源映射。`npm run assets:sync` 根据它生成忽略提交的运行时副本，应用目录不得手工维护同一素材。

## 静态资产规则

1. 图片不得烘焙产品文字、按钮或状态；文字由真实界面排版。
2. 原始生成尺寸保留，不在母版目录做无依据放大或有损重压缩。
3. 文件名采用 `<subject>-<surface>-<theme>-vN.ext`，版本变化必须产生新文件，不能静默覆盖既有母版。
4. 每张生成图必须在 `catalog.json` 记录尺寸、用途、提示词和 SHA-256。
5. 场景素材缺失时使用显式共享回退，不复制同一张图片伪装成多个场景专属素材。
6. `experiments/` 中的文件只有在经过验收、迁移到正式目录并登记进 `catalog.json` 后，才能被应用引用。
7. 用于页面交付的 JPEG 等有损派生文件必须登记进 `derivatives.json`，并由同一校验命令核对母版引用、尺寸和 SHA-256。

校验命令：

```powershell
node tools/validate-static-assets.mjs
```
