# 声景日常应用壳原型

这个目录验证一套适合日常使用的播放器结构：`首页 / 探索 / 创建 / 声景集` 是内容路由，播放器始终位于全局顶层，不属于任何页面。

声景是持续演化的环境，没有歌曲式进度、已播放时间或总时长。收起态由可点击的当前声景信息区和同规格的倒计时、总音量、播放/暂停控件组成；点击整条信息区展开或收起播放器，区内不另设方向按钮，倒计时与音量通过非模态 popover 按需设置。展开后这条控制轨保持原位，第一屏增加场景画面和轻重/简繁；图窗本身以低幅整框呼吸表达沉浸聆听入口，不常显按钮，下方真实内容自然露出并引导用户继续滚动，声景调节始终接续在播放器下方。

首页只负责把用户引向“创建”或“探索”，并提供一处可直接开始的精选声景，不再承载生成、推荐和历史记录等功能。探索与声景集只展示现有内容，不用没有真实差异的数据筛选制造功能感。创建任务仍在后台进行，完成后通过通知询问是否切换，不会中断当前声景。

当前生成任务仍是本地模拟，只提供“雨夜木屋”和“深夜海岸”两个与音频语义一致的可听样例。轻重、简繁、平稳/起伏、贴近/远处、基础声音层和七种设备听感会真实改变 Web Audio 处理链。素材库按环境、事件、媒介和我的声音分类：两段环境录音可直接混入当前声景，事件与媒介从用户选择的音频开始，额外声音层可以独立调整存在感、设备质感、静音和移除。

四个创建模板只会填充描述，不冒充已生成内容。外观、选择后播放、保留上次听感和本地存储管理集中在设置页；只有存在用户音频时才出现清空入口。用户偏好与内置环境层分配写入 `localStorage`，上传音频 Blob 及其层级设置写入 IndexedDB。真实场景拆解、声音检索或生成、生产级持续编排和错误恢复尚未接入，不应把这个原型当成后端能力证明。

## 代码边界

- `app.js` 只负责产品状态、DOM 绑定和各模块编排，不直接承载动画时间线或交叉淡化算法。
- `motion/runtime.js` 统一管理断点、指针能力和 `prefers-reduced-motion`；`motion/*-motion.js` 分别拥有导航、播放器、沉浸场和声景切换的生命周期。
- `audio/crossfader.js` 负责 Web Audio 等功率交叉淡化、四项整体编排参数、基础层与额外声音层控制，以及自然、Hi-Fi、胆机、收音机、电视、喇叭和耳机空间七种处理；Web Audio 不可用时退回媒体元素音量控制。
- `audio/storage.js` 负责浏览器偏好、上传音频 Blob 和层级设置的本地持久化，并等待 IndexedDB 事务完整提交；不承担云端同步。
- `visual-field.js` 只负责 OGL 膜片场的创建、暂停、场景更新和渲染状态，不参与页面结构切换。

播放器以一条可中断的单轴位移表达整面升起与下降，封面、主图和控制轨不参与共享元素飞行，也不跟随滚动缩放。全局控制轨会原位进入专注场，继续提供同一套当前声景、倒计时、音量和播放控制；专注场播放时会在 2.4 秒无操作后隐去顶部品牌与底部控制，指针、触摸或键盘输入会唤回，暂停时始终显示。场景切换采用最后一次意图优先，声音与画面并行过渡。临时 `will-change` 只在动画执行期间设置，离屏膜片场停止渲染。

```powershell
npm ci
npm run dev -- --port 4174
```

原型复用仓库内已经验收的品牌、Hero 与 Cover 位图母版，并使用 96px 透明品牌标记、480px 模板封面和 720/1280px 场景 JPEG 网页派生图降低首屏负担。GSAP 只承担播放器单轴升降、专注场温和显隐、导航状态和场景切换；OGL 只负责全屏膜片场。`prefers-reduced-motion` 会把空间位移收敛为即时、可读的状态变化。图标来自 Lucide，没有新增手绘 SVG。
