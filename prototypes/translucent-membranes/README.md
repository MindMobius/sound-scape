# 半透明膜片生成原型

这是一个完全独立、可丢弃的视觉技术实验，用于验证浏览器能否程序化生成声景当前品牌方向中的有机半透明膜片。

- `?variant=A`：自由声场，观察大面积叠色和拖拽重组。
- `?variant=B`：材料图谱，同时观察单片、双片与复合关系。
- `?variant=C`：暗场徽记，验证图标、封面和深色界面的表现。

实现只依赖浏览器原生 SVG、CSS 和 JavaScript。SVG 中的路径、穿孔遮罩、颜色、边缘与阴影均可独立导出，不依赖生成图片。

在本目录启动静态服务器：

```powershell
python -m http.server 10598
```
