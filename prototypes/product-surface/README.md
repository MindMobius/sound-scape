# 声景产品界面原型

这个独立、可丢弃的原型把 Image 2 生成的半透明膜片素材用于真实产品界面，而不是继续做素材陈列。

- `?variant=A`：安静聆听场域，默认使用路径。
- `?variant=B`：暗夜沉浸播放器，突出连续播放和空间氛围。
- `?variant=C`：声音图层工作区，验证高级编排密度。

三个方案共享播放状态、音量、轻重、简繁、后台生成和手动切换状态。界面素材直接引用 `assets/brand/` 中登记过的 RGB 静态母版，没有把背景烘焙图错误地当成透明切片叠加。

从仓库根目录启动静态服务：

```powershell
python -m http.server 10599
```

然后打开 `http://127.0.0.1:10599/prototypes/product-surface/?variant=A`。
