# 声景视觉研究与方向推导

## 设计命题

声景的视觉不应该说明“这里有自然声音”，而应该让人立刻感到：一句描述正在被组织成一个有深度、会变化、可以调节的声音空间。

所谓禅意，不采用竹、禅石、水墨、宣纸底色等直接符号，而采用更严格的设计纪律：有限元素、材料诚实、清楚的间隔、非对称平衡、慢而有因果的变化，以及对安静区域的尊重。

## 调研观察

### 1. 声音可以通过结构显形，而不是画成波形

- [Exploratorium 的振动实验](https://annex.exploratorium.edu/xref/exhibits/bells.html)展示了沙粒如何聚集在振动板的节点线上。可借鉴的是“声音决定形状”的因果关系，而不是照搬克拉尼图案。
- [MoMA 对 John Cage 图形乐谱的介绍](https://www.moma.org/magazine/articles/1154)说明图形记谱能把声音变成开放的视觉指令。[Fontana Mix](https://www.beyondnotation.com/)的透明叠片、点与曲线尤其接近声景的参数化编排机制。

### 2. 高级感来自材料被认真对待

- [Bang & Olufsen 的材料原则](https://www.bang-olufsen.com/en/gb/story/craft-matters)强调材料诚实、精密加工和表面处理，而不是用装饰模仿材料。
- [Beosound A5 Spaced Aluminium](https://www.bang-olufsen.com/en/au/story/beosound-a5-spaced-aluminium)把 3500 多个铝制圆片变成声音通道与识别特征的同一个系统。对声景的启发是：纹理必须同时承担声音、状态和品牌识别。

### 3. “空”必须是结构的一部分

- [nendo 的 The Space in Between](https://www.nendo.jp/en/works/nendo-the-space-in-between-2/)讨论了层与层、感官与感官之间的空间。声景可以让空隙表示距离、等待、衰减和听觉焦点，而不是把留白当成背景。
- [Hara Design Institute 的方法](https://hara.ndc.co.jp/en/about/)把触觉和日常感官视为设计资源。这里采用的是感官转换的方法，不采用“米白加日文字体”的表面风格。

### 4. 克制仍然可以具有巨大尺度

- [Ryoji Ikeda 的 data-verse](https://www.ryojiikeda.com/project/x_verse/)用极少色彩、精密数据与建筑尺度制造强烈体验。可借鉴的是尺度、同步和密度纪律，而不是黑底代码雨。
- [Hiroshi Sugimoto 的 Seascapes](https://www.sugimotohiroshi.com/seascapes-1/)用海与空气之间的一条水平关系承载时间感。地平线适合成为“当前声景仍在持续”的视觉基准，但必须补上产品自己的可编辑结构。

### 5. 看不见的世界可以被测绘

- [NOAA 的海底地形图](https://www.ngdc.noaa.gov/mgg/bathymetry/maps/)用等深线描述不可直接看见的海底形态。等值线可以映射声音距离、强度和空间扩散，但若直接使用会误读成地图产品。
- [Arup SoundLab](https://www.arup.com/en-us/services/digital-solutions/soundlab/)把尚未建成的空间声学转化为可体验、可比较的设计判断，证明“先听见未来空间”本身可以成为产品体验。

### 6. 细微不是低对比糊成一片

- [TAKEO PAPER SHOW 2014 SUBTLE](https://www.takeo.co.jp/en/exhibition/tps/2014.html)把压印、表面差异和微弱阴影当作内容。声景的纹理应在近看时成立、缩小时仍保留清楚轮廓，不能依赖噪点滤镜伪装质感。

## 七个原生方向

按与产品机制和使用场景的共鸣排序：

1. **静默共振**：声学节点与精密微孔形成可响应的品牌纹章，最能同时覆盖图标、界面状态和空间反馈。
2. **可听地形**：用等深线和声呐测绘组织声音距离、强度与来源，产品解释力强，但要避免地图软件感。
3. **开放乐谱**：用透明叠片、点和曲线表达可变编排，文化含量高，但可能过于实验音乐。
4. **感官之间**：以透明层、空隙和遮挡构成声音空间，最安静，但最容易误入玻璃拟态。
5. **暗室地平线**：用银盐海面、烟熏玻璃和一条持续地平线建立时间感；禅意最自然，必须补强可编辑性。
6. **精密聆听器**：把软件当作一件经过车削和阳极氧化的听觉器物，质感明确，但可能被误认成硬件品牌。
7. **数据静场**：用极少色彩和大尺度数据同步表现声音生成，冲击力强，但容易过度技术化。

类别惯性是“自然风景照片 + 居中播放键 + 柔和渐变”；它与相反的“霓虹波形 + 黑色玻璃面板”都不进入上述七个方向。

## 本轮候选判断

- **暗室地平线 / 主方向**：在受众识别上最符合安静聆听，在产品清晰度上需要结构性抬高。
- **静默共振 / 首选补充**：受众识别和产品机制都强，作为完整备选呈现；风险是变成音响品牌或克拉尼装饰。
- **多层黎明 / 竞争方案**：景深天然解释声源层次，受众识别强；风险是落入童话插画和冥想应用。
- **声场裁片 / 竞争方案**：叠片和裁线极清楚地解释参数化编排；风险是工具感压过聆听体验。
- **模块彩条 / 放弃**：保留跨媒介系统的一致性，不采用高饱和形态。
- **一比特桌面 / 放弃**：保留状态绝对清楚的纪律，不采用复古像素外观。
- **剪辑台 / 放弃**：保留不中断时间轴与待切换标记，不采用视频编辑器语义。
- **街头杂志密度 / 放弃**：只保留高级配置页敢于容纳真实信息密度的纪律。

## 对主方向的抬高

- 来自多层动画：地平线不是背景，声音层以真实遮挡和缓慢视差显出距离。
- 来自裁缝纸样：每个声源层都能读出来源、关系和可调边界。
- 来自一比特桌面：播放中、生成中、已就绪、待切换必须一眼可辨。
- 来自剪辑台：当前声景持续存在，新声景只在时间线上等待用户确认。
- 来自模块身份：同一个核心关系必须能无损缩放到图标、Banner、社交封面和界面。
- 来自高密度排版：高级配置可以密，但默认聆听界面必须静。

## 明确拒绝

- 不以莲花、禅石、竹叶、山水墨迹、圆相或音符作为主标志。
- 不把波形、均衡器柱、耳机轮廓或播放三角直接拼成 Logo。
- 不使用米白纸张、细衬线、朱红印章的整套“伪东方高级”模板。
- 不用紫蓝渐变、发光描边、玻璃卡片墙制造“AI 音频工具”气质。
- 不把生成图片中的文字当作最终字标；正式字标和界面文字必须在后续以真实字体与几何重建。
