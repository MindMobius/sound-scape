# Image 2 提示词

提示词目录镜像素材职责：

- `brand/backgrounds/`：跨场景背景母版。
- `brand/motifs/`：构图片段和纹章探索。
- `brand/atlases/`：材料与叠色校准图集。
- `scenes/`：按场景 ID 保存专属静态成片提示词。
- `experiments/`：动态和运行时研究，不进入静态产品清单。
- `explorations/`：被比较过的视觉方向和宣传元素探索。

正式静态图片的提示词路径必须登记在 `assets/catalog.json`。场景提示词成熟后使用 `design/prompts/scenes/<scene-id>/<slot>-vN.txt`。
