# 视觉验收预览

这里保存由正式母版派生的低分辨率总览，仅用于横向比较和视觉验收，不属于产品可消费资产。应用应始终通过 `assets/catalog.json` 引用原始文件。

`scene-heroes-contact-sheet-v1.png` 按 `assets/scenes/index.json` 的顺序展示首批六个场景 Hero。

`scene-covers-contact-sheet-v1.png` 以 3 x 2 网格展示首批六个场景 Cover，并附场景 ID 便于核对。

`brand-identity-proof.html` 展示品牌标记在 `16/24/32/64/128px`、深浅底和 Maskable 裁切中的真实浏览器渲染。
